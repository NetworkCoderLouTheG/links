Server Rules

General Rules

  • No cheating = Blocked/Banned if caught
  • No exploiting = Blocked/Banned if caught
  • No third-party apps (Game scripts/Tools) = Blocked/Banned if caught

Survivor Rules

  • Get killed = Eliminated
  • Didn’t escape = Eliminated

Killer Rules

  • No Slugging (not hooking downed survivors)
  • No kill = Eliminated
Elimination only applies when there is a queue in line

These rules are essential for a fair gameplay and must be followed by all players at ALL TIMES.
